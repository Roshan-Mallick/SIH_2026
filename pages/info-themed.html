01 · TECHNOLOGY STACK

Built for secure,
local-first execution.

The website manages the account and product layer. The desktop application performs local sandboxing, policy enforcement, scanning, local AI, and reporting.

WEB PLATFORM

Next.js + React

Landing page, dashboard, account, and downloads.

UI

Tailwind CSS

Responsive application interface.

BACKEND & DATABASE

Supabase + PostgreSQL

Authentication, users, licenses, subscriptions, and metadata.

PAYMENTS & HOSTING

Stripe + Vercel

Subscription billing and web deployment.

DESKTOP

Java + JavaFX

Cross-platform desktop interface and orchestration.

SECURITY ENGINE

C++20/23 + CMake

Low-level runtime security operations through local IPC.

SANDBOX

Docker

Isolated agent execution with filesystem, network, process, and resource policies.

LOCAL AI

Ollama + 2–3B model

Local explanations and reports from structured evidence.

SCANNING & STORAGE

Gitleaks + audit tools + SQLite

Deterministic security scanning and local audit storage.

REPORTS & DISTRIBUTION

HTML, JSON, SARIF + GitHub Releases

Actionable reports and installers for Windows, Linux, and macOS.
